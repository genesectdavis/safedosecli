# SafeDose CLI

## Problema
Pessoas esquecem horários de medicamentos, causando riscos à saúde.

## Solução
Aplicação CLI para gerenciar medicamentos e horários.

## Funcionalidades
Adicionar medicamentos
Listar medicamentos
Marcar como tomado

## Tecnologias
Python
Pytest
Ruff

## Instalação
pip install -r requirements.txt

## Execução
python src/main.py

## Testes
pytest

## Lint
ruff check .
